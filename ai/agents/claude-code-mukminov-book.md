# Claude Code: Ranas Mukminov’s Developer Guide

A Russian-language book by Ranas Mukminov (2026) about agentic development with Claude Code. Covers setup, coding, refactoring, debugging, tests, databases, Git, MCP, automation, DevOps and security.

The practical section includes a SaaS application, marketplace REST API, Telegram bot, Go CLI, Chrome extension and legacy-code migration. The supplied PDF contains 249 pages.

Useful as a learning reference. Testing, project context, MCP and agent limitations are priority topics for our workflow. Verify commands and configuration against current official documentation before use.
