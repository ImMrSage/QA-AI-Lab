# Мобильное приложение

Место для будущего Android-приложения; распространение через Google Play — позднейший этап.

Переиспользуйте знания, стабильные ID и подходящие ресурсы локализации веб-приложения. Нативная навигация и представление могут отличаться. Мобильный framework будет выбран отдельно; запускаемого приложения здесь пока нет.

См. [архитектуру](../../docs/architecture.md).
