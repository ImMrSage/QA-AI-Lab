# Веб-приложение

Статическая библиотека и адаптивный reader. Из корня запустите `python scripts/preview.py`, затем откройте `http://127.0.0.1:8001/apps/web/`. Локальный сервер отправляет `Cache-Control: no-store`, чтобы возврат из заметки не показывал устаревшую библиотеку HTTP-кеша. Используйте новый порт вместо старой кешированной вкладки.

Разработка поддерживает просмотр до коммита и публикации. Опубликованное приложение должно работать на телефоне и компьютере. Выберите English или Русский в верхней панели; язык сохраняется и передаётся во внутренних ссылках. Русский контент повторяет пути внутри `locales/ru/`. Если перевода нет, явно показывается английский вариант.

Карточки открывают полные оформленные заметки с оглавлением, таблицами, кодом и Mermaid. Markdown-ссылки остаются в reader. DOMPurify очищает HTML, Mermaid работает в строгом режиме. Реестр подборки связывает все двадцать разборов дайджеста.

Собранные assets включены в Git, поэтому чтению не нужны CDN или npm. После изменения `reader.js` выполните `npm ci` и `npm run build` в этой папке и закоммитьте `assets/` вместе с исходниками. Прямое открытие `file://` не поддерживается; развёртывание должно включать пути контента репозитория и приложение.
