# Веб-приложение

Тематическое пространство, библиотека с поиском, компактный каталог инструментов, оригинальные PDF и список источников со связями. Из корня запустите `python scripts/preview.py`, затем откройте `http://127.0.0.1:8001/apps/web/`. Локальный сервер отправляет `Cache-Control: no-store`, чтобы возврат из заметки не показывал устаревшую библиотеку HTTP-кеша.

Разработка поддерживает просмотр до коммита и публикации. Опубликованное приложение должно работать на телефоне и компьютере. Выберите English или Русский в верхней панели; язык сохраняется и передаётся во внутренних ссылках. Русский контент повторяет пути внутри `locales/ru/`. Если перевода нет, явно показывается английский вариант.

Карточки открывают полные оформленные заметки с оглавлением, таблицами, кодом и Mermaid. Markdown-ссылки остаются в reader. DOMPurify очищает HTML, Mermaid работает в строгом режиме. Реестр подборки связывает все двадцать разборов дайджеста.

Собранные assets включены в Git, поэтому чтению не нужны CDN или npm. Установите зависимости через `npm ci`, затем выполните `npm run build` в этой папке: команда обновляет `catalog.json` по заметкам и PDF репозитория и собирает reader. Для генерации каталога нужен Python. Коммитьте каталог и изменённые assets вместе с исходниками. Прямое открытие `file://` не поддерживается; развёртывание должно включать пути контента репозитория и приложение.

`workspace.js` содержит тематические связи и краткие двуязычные описания инструментов. Отдельные инструменты исключены из ленты статей; сравнения и руководства по процессам остаются статьями. URL сохраняет раздел, язык, запрос и фильтры. Reader возвращает на предыдущую страницу, а при прямом открытии использует проверенную ссылку на библиотеку. Заглушки профиля и переключения темы удалены.
