# Claude Code: руководство Ранаса Мукминова

Русскоязычная книга Ранаса Мукминова (2026) об агентной разработке с Claude Code. Охватывает настройку, работу с кодом, рефакторинг, отладку, тесты, базы данных, Git, MCP, автоматизацию, DevOps и безопасность.

Практическая часть включает SaaS-приложение, REST API маркетплейса, Telegram-бота, CLI на Go, Chrome-расширение и миграцию легаси-кода. В предоставленном PDF 249 страниц.

Полезна как учебный справочник. Для нашего workflow приоритетны темы тестирования, контекста проекта, MCP и ограничений агента. Команды и способы настройки нужно сверять с актуальной официальной документацией перед применением.

Проверены титульные страницы, оглавление и предисловие. Остальные главы не прочитаны; примеры кода не запускались и не проверялись. Полный технический разбор книги пока не выполнен.
