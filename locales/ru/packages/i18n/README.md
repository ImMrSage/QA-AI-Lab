# Общая локализация

Английский `en` и русский `ru` активны в интерфейсе; немецкий запланирован. Параметр `lang` в URL выше сохранённого выбора. Русские статьи лежат в `locales/ru/<canonical-path>` с тем же ID; относительные ссылки разрешаются от основного пути. Отсутствующий перевод вызывает явное предупреждение с английской статьёй `lang=en`.

Все текущие заметки, каталоги, реестры и связанные руководства имеют русский вариант. Необработанные источники не переводятся и не считаются разобранными. Пустые темы имеют заглушки обоих языков. Перевод разбора не означает изучение ранее непрочитанных глав.

Веб-прототип использует `apps/web/i18n.js` для фраз и `apps/web/card-translations.js` для заголовков и описаний по ID. JSON в `packages/i18n/locales/` — заготовки будущего общего кода; текущий web их не читает.

Храните фразы целиком, поддерживайте подстановки и формы множественного числа, форматируйте даты и числа по локали. Библиотека локализации будет выбрана с framework приложения.

Английский — явный fallback. Языки статьи и интерфейса учитываются отдельно. Смена языка сохраняет материал, но сбрасывает раздел из-за других якорей переведённых заголовков.

Переводы сохраняют ID, URL, код, оговорки и даты разбора. Переводите полностью, включая таблицы и подписи Mermaid. `python scripts/check_translations.py` проверяет охват и структуру; проверки дополняют редактуру, но не доказывают качество перевода. Пересобирайте reader после изменения кода и проверяйте оба языка, сохранение выбора, ссылки и адаптивность.
