# Общий контракт контента

Корневые папки знаний — основной источник web и mobile: `qa/`, `ai/`, `tools/`, `playbooks/`, `glossary/`. `inbox/` содержит необработанное и не должен публиковаться автоматически.

Пакет зарезервирован для общих схем, валидации и загрузки. Не дублируйте библиотеку внутри каждого приложения.

Публикуемые записи используют стабильные ID и язык `en` или `ru`. Английские файлы находятся в корне, русские повторяют пути внутри `locales/ru/`. Записям нужны заголовок, summary, тема, теги, формат, источники и связанные ID. Для инструментов также нужны решаемая проблема, практика, ограничения и исходный URL.

Переводы разделяют один ID. README и INDEX — навигация и документация, а не автоматически публикуемые записи знаний.
