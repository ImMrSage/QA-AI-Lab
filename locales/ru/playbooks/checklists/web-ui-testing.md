# Тестирование Web UI

## Матрица компонентов

| Компонент | Проверки |
| --- | --- |
| Кнопки | Действие, выход из hover, состояния нажатия/недоступности/загрузки, клавиатура |
| Текст и поиск | Подписи, placeholders, автозаполнение, результаты; см. формы |
| Checkbox и radio | Выбор, группировка, зависимости, клавиатура |
| Выпадающий список | Открыть/закрыть, выбор, необязательный поиск, сохранение выбора |
| Ссылка | Адрес, заявленная новая вкладка, различимый вид |
| Изображение | Ошибка загрузки, подходящий текстовый эквивалент, действие по клику при наличии |
| Таблица | Точные значения, сортировка, фильтрация, пагинация |
| Модальное окно | Открыть/закрыть, действия, блокировка фона, определённая политика закрытия |
| Подсказка | Обнаружимость, положение, закрытие, альтернатива для клавиатуры и касания |
| Карусель | Ручная навигация, автопрокрутка при наличии, пауза, адаптивное содержимое |
| Хлебные крошки | Иерархия, адреса, указание текущей страницы |
| Выбор даты | Ввод текстом/календарём при поддержке, пределы, локаль, зависимые поля |

Для модального окна проверьте вход фокуса, удержание внутри и возврат после закрытия. См. [W3C о диалогах](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). Placeholder не должен быть единственной подписью поля.

## Пагинация и общие состояния

- [ ] Проверить ноль, одну и несколько страниц; первую/последнюю границы; вперёд/назад.
- [ ] Менять размер страницы, сортировку и фильтры; проверять счётчики и доступные записи.
- [ ] Добавлять и удалять записи, включая последнюю на странице.
- [ ] Проверить указатель текущей страницы и заданное поведение обновления/возврата.
- [ ] Изучить состояния загрузки, пустоты, ошибки, недоступности и успеха.
- [ ] Проверить узкие экраны, zoom, клавиатуру и поддерживаемые браузеры.
- [ ] Оценить смысл для screen reader, видимость фокуса, контраст и обрезку макета.
- [ ] Для поддерживаемых локалей проверить переводы, даты, числа и валюты.
- [ ] Измерить загрузку по согласованному бюджету в репрезентативной сети.

## Практические принципы

Скрытая пагинация, сохранение страницы, закрытие модального окна внешним кликом и очистка формы после отправки — решения дизайна, а не универсальные требования. Радиогруппа обычно выбирает один вариант, но не обязательно позволяет снять его напрямую. Чек-лист не является аудитом соответствия WCAG.
