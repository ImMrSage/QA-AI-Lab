# FakeData: Настраиваемые тестовые данные

Web-приложение для генерации синтетических данных для тестирования, разработки и симуляций. Позволяет задавать названия и типы полей и просматривать сгенерированный код.

## Рекомендация

Подходит для данных прототипа и проверок форм или API. Граничные и невалидные случаи задавайте отдельно: правдоподобные случайные данные не гарантируют покрытие. Повторно используемые регрессионные наборы храните в проекте.
