# DB Quacks: интерактивная практика SQL

[Открыть DB Quacks](https://dbquacks.com/).

Браузерная обучающая игра по SQL на DuckDB-WASM. Есть курс из 38 уровней, тематические задачи и еженедельные головоломки. По информации сайта, доступ бесплатный; регистрация необязательна, вход позволяет сохранять прогресс между устройствами и участвовать в рейтинге под своим именем.

## Рекомендация

Используйте вместе со [шпаргалкой SQL для тестировщика](../../qa/api-testing/sql-for-testers.md): тренируйте фильтрацию, JOIN, группировку и подзапросы, сравнивая результат с ожидаемыми строками. Синтаксис DuckDB может отличаться от базы вашего проекта.

Проверены сайт и FAQ; упражнения не запускались. Это учебный ресурс, а не клиент производственной базы.
