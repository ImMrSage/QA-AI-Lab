# Docker Zero to Hero: практический курс-репозиторий

[Открыть курс-репозиторий](https://github.com/iam-veeramalla/Docker-Zero-to-Hero).

README знакомит с контейнерами, архитектурой Docker, установкой, сборкой, запуском и публикацией образа. Отдельные файлы посвящены командам, сетям и томам; есть каталог примеров и ссылка на видеоплейлист.

Начните с различия образа и контейнера, затем соберите и запустите небольшой пример, после переходите к сетям и сохранению данных. Для QA это путь к пониманию воспроизводимых тестовых окружений и зависимостей.

Примеры установки рассчитаны на Ubuntu/AWS; выбирайте инструкции под свою ОС. Проверен README, а не все уроки и видео. Примеры не запускались.
