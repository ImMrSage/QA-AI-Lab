# Patterns.dev: Паттерны web-разработки

Бесплатный учебный справочник по паттернам JavaScript, React и Vue, рендерингу и производительности web-приложений, с практическими примерами и визуальными объяснениями.

## Рекомендация

Для QA AI Lab начните с оптимизации загрузки, разделения bundle и виртуализации списков. Выбирайте паттерн под конкретную проблему и измеряйте эффект; каталог не является обязательным чек-листом внедрения. Проверены главная страница и список тем; отдельные главы не анализировались.
