# Bundlephobia: оценка стоимости npm-зависимости

## На какой вопрос отвечает

[Bundlephobia](https://bundlephobia.com/) оценивает влияние npm-пакета на frontend bundle до добавления зависимости в проект. Найдите точную версию, чтобы изучить размер, состав, exports и исторический тренд, либо используйте beta-сканирование package.json для первичной оценки нескольких зависимостей.

Сервис помогает сравнить кандидатов, заметить тяжёлые транзитивные зависимости и проверить, нельзя ли использовать меньший import или возможность платформы.

## Процесс проверки

1. Найдите точную версию, предлагаемую для lockfile.
2. Сравните minified и compressed size, состав пакета и доступные exports.
3. Определите, нужен ли весь пакет или отдельный importable subpath.
4. Сравнивайте альтернативы по возможностям и стоимости поддержки, а не только по размеру.
5. Добавьте кандидата в отдельной ветке и измерьте production-сборку.
6. Проверьте lazy loading, code splitting и tree-shaking в bundler проекта.
7. Запустите репрезентативную страницу или сценарий и измерьте переданный JavaScript, parse/evaluation time и пользовательскую производительность.
8. Если размер влияет на релиз, добавьте владельца bundle budget и регрессионную проверку.

## Как читать оценку

| Сигнал Bundlephobia | Чего он не доказывает |
| --- | --- |
| Стандартный размер сборки | Точное количество байтов в bundler и target проекта |
| Размер после gzip | Результат Brotli, cache и уже общие для chunks байты |
| Список exports и состав | Что tree-shaking сработает для выбранного import и конфигурации |
| Исторический тренд | Runtime-производительность, память или качество поддержки |
| Успешная сборка сервиса | Совместимость с framework, SSR и browser matrix приложения |

Фактическое влияние зависит от версии, import path, bundler, формата модулей, целевых браузеров, minifier, дублирования и code splitting. Маленькая зависимость всё равно может быть медленной или небезопасной; большая может быть оправдана, если устраняет дублирование или загружается только по требованию.

## Завершите решение о зависимости

Кроме размера проверьте лицензию, активность релизов, maintainers, advisories, транзитивные зависимости, браузеры, types, accessibility и стоимость замены. Ошибка сборки Bundlephobia означает отсутствие оценки, а не доказательство непригодности пакета. Скан package.json может раскрыть названия приватных пакетов, поэтому не отправляйте закрытый manifest без разрешения.
