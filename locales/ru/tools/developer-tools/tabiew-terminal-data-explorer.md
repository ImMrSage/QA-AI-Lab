# Tabiew: просмотр табличных данных в терминале

## Для чего подходит

[Tabiew](https://github.com/shshemi/tabiew) — лёгкий терминальный интерфейс для просмотра и запросов к табличным данным. Поддерживает CSV, TSV, Parquet, JSON, JSONL, Arrow, файлы фиксированной ширины, SQLite, Excel, Avro, HTML-таблицы и Markdown-таблицы. Внутри есть SQL-запросы, фильтры, сортировка, быстрый поиск, работа с несколькими таблицами, графики и более 400 тем.

В QA инструмент удобен для быстрой проверки выгрузок тестовых данных, результатов API, журналов событий и снимков базы данных. Можно открыть несколько файлов одновременно, а параметр `--max-rows` позволяет сначала изучить ограниченную выборку большого набора данных.

## Практическая рекомендация

1. Начните с `tw <файл>` и проверьте определённую схему и выборку строк.
2. Используйте `/` для быстрого поиска, а палитру команд (`:`) — для Query, Filter, Order, Select, Cast, Import, Export и Schema.
3. Применяйте SQL, когда сравнение, агрегация или join понятнее ручного просмотра.
4. Сохраняйте исходный файл и экспортируйте результат в новый путь.
5. Успешный импорт не доказывает корректность данных: проверьте кодировку, разделители, null, определённые типы, даты и возможное усечение строк.
6. Не открывайте production-выгрузки с секретами или персональными данными на неуправляемом компьютере.

Tabiew — локальный инструмент исследования, а не замена воспроизводимым проверкам в автотестах. Способы установки и поддерживаемые форматы могут изменяться, поэтому актуальными источниками остаются README и страница релизов проекта.
