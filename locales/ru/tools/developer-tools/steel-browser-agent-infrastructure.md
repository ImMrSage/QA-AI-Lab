# Steel Browser: Браузерная инфраструктура для AI-агентов

Открытый Browser API для AI-агентов и web-автоматизации. Управляет Chrome-сессиями, состоянием браузера и извлечением страниц; совместим с Playwright, Puppeteer и Selenium.

## Рекомендация

Полезен для повторного использования браузерных сессий, извлечения страниц и отладки работы агентов. Доступен самостоятельный хостинг по лицензии Apache-2.0; для запуска нужны собственные вычислительные ресурсы. Steel Cloud — отдельный управляемый сервис. Храните состояние авторизованных сессий приватно.
