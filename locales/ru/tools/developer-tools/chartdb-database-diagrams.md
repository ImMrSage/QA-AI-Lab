# ChartDB: схемы баз данных

Визуальный редактор схем баз данных: таблицы, поля и связи в ER-диаграммах. Поддерживает импорт метаданных схемы и экспорт диаграмм и SQL DDL.

## Рекомендация

Полезен для изучения структуры БД и планирования проверок связей. Сверяйте ключи и ограничения с реальной схемой; экспорт DDL проверяйте перед применением. Для закрытых схем рассмотрите self-hosted версию.
