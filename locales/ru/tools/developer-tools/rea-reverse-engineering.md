# REA: реверс-инжиниринг с AI-агентом

REA связывает агента через MCP с инструментами анализа нативных бинарных файлов, JavaScript/Electron, .NET и поведения браузера. Помогает исследовать конкретную функцию по свидетельствам; не восстанавливает автоматически исходный проект целого приложения.

## Применение и границы

| Цель | Полезный вопрос | Ограничение |
| --- | --- | --- |
| PDF-приложение | Как работает выбранная локальная операция с документом? | Воссоздать одно поведение — не то же самое, что восстановить Acrobat |
| Процедурный 3D-инструмент | Как обрабатываются параметры геометрии и преобразования файлов? | Проверяйте топологию, нормали, UV, единицы и совместимость материалов |
| Локальный AI-генератор | Какие компоненты готовят вход и обрабатывают результат? | Кода инференса недостаточно без весов модели и связанных компонентов |
| Облачный генератор | Что отправляет и показывает клиент? | Анализ клиента не раскрывает серверный код, веса и обучающие данные |

## Рекомендация

Начните с небольшой программы, которую вправе исследовать, одной функции и синтетических входных данных. Зафиксируйте ожидаемый результат, исследуйте только нужный компонент, затем проверьте независимую реализацию на крайних случаях. Лицензии целевой программы и анализаторов действуют отдельно; лицензия REA не даёт доступа к платным функциям или проприетарным ассетам.

Для нативного анализа в Windows сначала проверьте конкретный релиз REA и поддержку провайдера: руководство Ghidra описывает экспериментальную поддержку, а не полное равенство возможностей. Не считайте, что все функции repository main уже присутствуют в установленном npm-пакете.

## Безопасность

REA — мощный локальный инструмент, а не песочница. Используйте изолированную VM без личных файлов и активных аккаунтов, начинайте со статического анализа и отдельно разрешайте запуск целевой программы. Просматривайте изменения конфигурации агентов при установке и используйте официальные ссылки распространения. Локальный анализ не гарантирует приватность AI-обработки: результаты могут попасть в контекст провайдера модели. Не передавайте секреты, проприетарные бинарные файлы и конфиденциальные документы без необходимости.

Изучены README, политика безопасности, манифест пакета, shell-установщик и руководство Windows. REA не устанавливался, не запускался и не проходил полный аудит; безопасность и совместимость не сертифицированы.
