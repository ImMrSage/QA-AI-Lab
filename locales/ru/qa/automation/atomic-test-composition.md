# Композиция компонентов UI-тестов

## Практическое применение в QA

| Повторяющийся элемент | Возможное выделение |
| --- | --- |
| Общая навигация | Компонент навигации |
| Адресный блок | Компонент формы адреса |
| Повторяющееся сохранение | Узкое действие с явными проверками результата |

Выделите одну повторяющуюся форму и сравните дублирование кода, область локаторов и понятность диагностики до перестройки всего набора тестов.

## Практические принципы

Утверждение, что Page Objects не позволяют переиспользовать компоненты, слишком категорично. Полезный вопрос — композиция и ответственность, а не необходимость пяти именованных слоёв в каждом проекте. Page Objects не ограничены Selenium. В примерах источника есть несогласованности синтаксиса и параметров; это иллюстрации, а не готовый исполняемый код. Глобальные селекторы и обёртки, лишь переименовывающие API, могут добавить косвенность без улучшения смысла теста.
