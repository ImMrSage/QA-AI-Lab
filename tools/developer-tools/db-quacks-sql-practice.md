# DB Quacks: Interactive SQL Practice

[Open DB Quacks](https://dbquacks.com/).

A browser-based SQL learning game using DuckDB-WASM. It offers a 38-level tutorial, themed challenges and weekly puzzles. The site describes access as free; registration is optional, with sign-in enabling cross-device progress and named leaderboard entries.

## Recommendation

Use it alongside [SQL for testers](../../qa/api-testing/sql-for-testers.md): practice filtering, joins, grouping and subqueries, then compare your result with the expected rows. DuckDB syntax can differ from the database used by your project.

The site and FAQ were reviewed; exercises were not executed. This is a learning resource, not a production database client.
