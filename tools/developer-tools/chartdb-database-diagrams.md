# ChartDB: Database schema diagrams

A visual database schema editor for tables, columns and relationships in ER diagrams. Supports schema metadata import and diagram and SQL DDL export.

## Recommendation

Useful for understanding database structure and planning relationship checks. Verify keys and constraints against the real schema and review exported DDL before applying it. Consider self-hosting for private schemas.
