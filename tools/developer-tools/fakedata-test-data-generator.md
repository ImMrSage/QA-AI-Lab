# FakeData: Custom test data

A web app for generating synthetic data for testing, development and simulations. Define field names and data types and preview the generated code.

## Recommendation

Useful for prototype datasets and form or API checks. Add explicit boundary and invalid cases separately: plausible random data does not guarantee test coverage. Keep reusable regression datasets in the project.
