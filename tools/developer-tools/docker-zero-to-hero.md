# Docker Zero to Hero: A Practical Learning Repository

[Open the course repository](https://github.com/iam-veeramalla/Docker-Zero-to-Hero).

The README introduces containers, Docker architecture, installation and building, running and publishing an image. Separate files cover commands, networking and volumes; an examples directory and linked video playlist support practice.

Start with the image/container distinction, then build and run a small example before exploring networking and persistence. For QA, use this learning path to understand reproducible test environments and dependencies.

Installation examples target Ubuntu/AWS; choose installation instructions for your own OS. The README was reviewed, not every lesson or video. Examples were not executed.
