# Steel Browser: Browser infrastructure for AI agents

An open-source browser API for AI agents and web automation. Manages Chrome sessions, browser state and page extraction; works with Playwright, Puppeteer and Selenium.

## Recommendation

Useful when agents need reusable browser sessions, page extraction and debugging. Self-hosting is available under Apache-2.0; running the service requires your own computing resources. Steel Cloud is a separate managed option. Keep authenticated session state private.
