# AIToolTree: Discovering AI Tools Critically

## Use it for discovery

[AIToolTree](https://aitooltree.com/) is a free directory intended to help users browse and filter AI products. It can shorten the first search for a transcription, image, writing, coding or productivity tool. A directory entry is a candidate for evaluation, not evidence that the product is safe or suitable.

## Evaluation workflow

1. Describe the job, data involved and required output before browsing.
2. Create a shortlist by capability rather than popularity wording.
3. Open the vendor's official site and confirm that the product still exists.
4. Check pricing, usage limits, supported platforms, export formats and deletion controls.
5. Read privacy terms and identify where prompts, files and results are processed and retained.
6. For work data, confirm organizational approval, subprocessors and applicable data location.
7. Test with synthetic or non-sensitive material and compare accuracy, latency and failure behavior.
8. Record the date and evidence behind the decision; AI services change frequently.

| Signal | What to verify |
| --- | --- |
| “Free” | Limits, trial expiration, paid exports, watermarking and commercial-use terms |
| “Popular” or “trending” | Ranking method, measurement period and sponsorship |
| “Verified” | Published criteria, reviewer identity, test date and reproducible evidence |
| Direct link | Final domain, publisher identity and whether the link is affiliate-tracked |
| File upload | Retention, model training, deletion, access control and incident handling |

## Current limitations

The site states that tools are checked for AI performance, credibility and uptime, but does not publish the method or evidence on the accessible page. It also describes both live daily additions and weekly list updates. Tool cards are dynamically loaded and may not be visible to search or accessibility tools. Generic testimonials should not influence a technical or procurement decision.

Use AIToolTree as a search starting point. Prefer official vendor documentation, hands-on tests and an approved risk review for the final choice.
