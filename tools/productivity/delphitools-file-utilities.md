# delphitools: Local Browser Utilities for Files and Media

## What it is

[delphitools](https://delphi.tools/) is a free, open-source collection of focused browser utilities. The current site says processing happens in the browser, without accounts, tracking or data collection. The former tools address at tools.rmv.fyi redirects to delphi.tools; rmv.fyi itself is now the creator's portfolio.

## Choose by task

| Need | Useful tools |
| --- | --- |
| Prepare images | Background Remover, Image Converter, Compressor, Clipper, Splitter, Stitcher and Metadata Stripper |
| Create web assets | Image Tracer to SVG, SVG Optimiser, Favicon Generator and Base64 Encoder |
| Social media | Seamless Scroll Generator, Social Media Cropper, Watermarker and Matte Generator |
| Work with colour | Palette Extractor and Generator, gradients, harmonies, Contrast Checker and Colour Blindness Simulator |
| Convert documents | Markdown, HTML, Word, LaTeX, EPUB and other formats through Document Converter |
| Inspect PDFs | PDF Preflight, Organiser, Compressor, Rotate & Crop, page numbers and image conversion |
| QA and development | JSON Formatter, Regex Tester, HTTP Status, JWT Decoder, Request Builder and UUID Generator |

The current catalogue confirms adding watermarks, but does not list a watermark-removal tool. PDF preflight in the browser is useful for quick checks; the separate native [Taxiway](https://rmv.fyi/projects/taxiway/) project offers a deeper print-focused inspection on Apple silicon.

## Safe working rules

1. Confirm the address is delphi.tools before dropping a file.
2. Local browser processing reduces upload exposure, but still use organization-approved tools for confidential material.
3. Remove metadata deliberately and verify the exported file; conversion can change colour profiles, fonts, transparency, links or accessibility.
4. Treat background removal and raster tracing as drafts that need edge and geometry review.
5. Check contrast against the actual foreground, background, font size and applicable WCAG target.
6. Keep the original file and compare dimensions, format, size and visible output after processing.
7. For print, archival, legal or regulated deliverables, validate with the required specialist workflow rather than relying on one browser check.
