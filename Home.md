## Rules

- Markdown and Git remain the source of truth.
- English notes stay at their canonical paths; Russian counterparts stay under `locales/ru/`.
- Bases are dynamic views over frontmatter, not separate copies of the content.
- Semantic indexes are derived and may be rebuilt.
- Review agent-written changes through Git and run the repository checks before publishing.
